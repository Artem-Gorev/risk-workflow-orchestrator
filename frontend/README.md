# RiskFlow Frontend

Русскоязычный интерфейс для запуска расчётов, проверки результатов и диагностики очереди RiskFlow. Требуются Node.js 22.12+ или 24+ и npm. Версии зависимостей зафиксированы в `package-lock.json`.

## Локальный запуск

1. Распакуйте архив бэкенда и поместите папку `frontend/` в корень проекта или в отдельный каталог.
2. В корне бэкенда выполните `sh scripts/start-local.sh` при запущенном Docker. В локальном `.env` бэкенда укажите `PUBLIC_ORIGIN=http://localhost:5173` и примените настройку командой `docker compose up -d --wait backend` (сохраните остальные значения `.env`).
3. В папке `frontend/` выполните

   ```sh
   npm ci
   npm run dev
   ```

4. Откройте [http://localhost:5173](http://localhost:5173). Для подтверждения готовности API откройте [проверку готовности](http://127.0.0.1:8000/health/ready).

Vite проксирует `/api/v1/*` и `/health/ready` на `http://127.0.0.1:8000`. Надпись «API подключён» появляется после успешного ответа `/health/ready`. Для другого адреса API задайте `BACKEND_URL` в `frontend/.env.local` и перезапустите Vite. В `PUBLIC_ORIGIN` укажите точный origin из адресной строки, включая протокол и порт. При серверной авторизации в режиме `proxy` идентификатор пользователя передаёт доверенный прокси.

## Сборка и проверка

```sh
npm run build
npm run smoke
```

Сборка записывается в `dist/`. Команда `npm run smoke` при запущенных Vite и API создаёт задачу ликвидности, запрашивает очередь и проверяет результат, историю событий и идемпотентность повторной отправки. Для проверки по другому адресу передайте его аргументом, например `npm run smoke -- http://localhost:4173`.

Для локального просмотра сборки используйте `npm run preview` и `PUBLIC_ORIGIN=http://localhost:4173` на бэкенде. Для развёртывания разместите `dist/` на веб-сервере и направьте запросы `/api/v1/*` и `/health/ready` с того же origin в FastAPI. Ссылки на задачи, серии и демонстрации работают через URL-фрагменты, поэтому веб-серверу достаточно обслуживать `index.html`.

Измерения PostgreSQL появляются после эксперимента на бэкенде. На Docker-стенде его можно запустить из корня бэкенда командой `docker compose exec backend python -m backend.analytics.benchmark`.
